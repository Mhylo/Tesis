# referencia/

Código de terceros contra el que se contrastó el propio. No se modifica.

| Carpeta | Contenido |
|---|---|
| [`zhao2020/`](zhao2020/) | El código original del MPASM de Zhao et al., *Opt. Lett.* 45, 5937 (2020), publicado en figshare (doi:10.6084/m9.figshare.12972872) con licencia CC BY 4.0, que conserva. `MatrixDft.py` y `Light.py` son de donde parten los propagadores de `CamposT/`; `scripts/retro_mpasm.py` copia su `MatrixDftCPU` tal cual para compararse con él. |
| `carlos/` | Clones de pyDHM, DLHM-model y DLHM-processing-tools (pyLHM). No están en el repositorio: se clonan de GitHub y se dejan corriendo con `scripts/parchar_referencias.py`, como dice el [README](../README.md#referenciacarlos). |
